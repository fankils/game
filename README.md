# Игра-платформер «Спасение кота»

Небольшая браузерная игра-платформер, созданная на чистом JavaScript (ES6 Modules) с использованием HTML5 Canvas API.

## Управление
*   **A / D** или **Стрелки влево/вправо** — движение персонажа.
*   **Space** или **W** (или Стрелка вверх) — прыжок.
*   На мобильных устройствах автоматически появляются экранные кнопки.

## Как запустить локально
1. Откройте папку с проектом в VS Code.
2. Нажмите правой кнопкой мыши на `index.html` и выберите **"Open with Live Server"**.
*(Из-за использования ES-модулей игра не запустится при простом открытии файла двойным кликом, нужен локальный сервер).*

## Функционал игры
*   **Физика и коллизии:** Реализована гравитация, плавное движение, прыжки (запрещен повторный прыжок в воздухе) и точные столкновения с платформами (сбоку, сверху, снизу).
*   **Игровая механика:** Сбор трех рыбок, опасная зона с огнем, финиш.
*   **Условия:** Победа засчитывается только если собраны все рыбки и достигнут кот. Поражение — при падении в пропасть или касании огня.
*   **Интерфейс:** Система подсчета очков, кнопки старта, паузы (также срабатывает при сворачивании вкладки) и рестарта.
*   **Сохранение:** Лучший рекорд сохраняется в `localStorage` браузера.
*   **Адаптивность:** Поддержка сенсорного управления для телефонов.

## Использование нейросети
*   **Нейросеть:** При выполнении задания использовалась нейросеть **DeepSeek**.
*   **Время выполнения:** Примерно 1.5 - 2 часа.
*   **Что сделано с помощью нейросети:** Нейросеть сгенерировала базовую архитектуру классов (Player, Platform, Game), написала математику игрового цикла с учетом `dt` (delta time), реализовала логику коллизий и предоставила шаблон адаптивного CSS для мобильного управления. Финальная настройка физики (сила прыжка, гравитация) и расположение платформ настраивались вручную.

## Полезные промпты
1. **Основной проект:** «Создай небольшой платформер на HTML/CSS/ванильном JS с Canvas. Нужны index.html, style.css, ES-модули main.js, Game.js, Player.js, input.js и collision.js».
2. **Коллизии:** «Реализуй систему обнаружения коллизий между прямоугольными объектами для платформера. Учитывай прежнее и новое положение, чтобы герой не проваливался сквозь платформу».
3. **Мобильное управление:** «Добавь экранные кнопки влево, вправо, прыжок для телефона с поддержкой удержания. Сохрани клавиатуру и физику».
